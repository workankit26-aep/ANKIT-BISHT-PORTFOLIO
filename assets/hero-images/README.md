# Hero Images

This folder is reserved for the portfolio's hero-section images.

## How to use

- Add hero images to this folder so they stay organized in one place.
- Use clear, lowercase filenames with hyphens, for example `ankit-portrait.webp` or `hero-background-01.jpg`.
- Prefer optimized WebP or AVIF images; use JPG/PNG when needed.
- Keep the original image and any alternate hero versions here so you can swap them later.
- When changing the hero image on the website, update the image path in `index.html` or the relevant rule in `style.css` to match the exact filename.

## Recommended image specs

- Landscape artwork/background: around 1920 × 1080 px.
- Portrait cutout/photo: high-resolution image with a clean background where possible.
- Compress images for fast loading and provide descriptive alt text for meaningful photos.
