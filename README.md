# Ankit Bisht — Portfolio

A responsive, dark editorial portfolio starter for Ankit Bisht, inspired by the visual direction of the supplied reference site. Built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and editable copy
- `style.css` — styling, responsive layouts, and motion
- `script.js` — mobile menu, project filters, and active navigation

## Personalize before publishing
1. Replace the six example project cards in `index.html` with real work titles, thumbnails, and URLs.
2. The contact email is set to `work.ankit26@gmail.com`.
3. The About section now describes Ankit as a Video Editor & Motion Graphics Artist with 6+ months of experience. Update any details that need more precision.
4. Add original portfolio images/videos in the project cards. The current abstract visuals are starter placeholders. Instagram and YouTube links can be added when available.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Choose branch **main** and folder **/(root)**, then save.
4. Wait for GitHub Pages to publish the site; the URL will appear in the Pages settings.

No build step or package installation is required.
